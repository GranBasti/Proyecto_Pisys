## Proyecto_Pisys
  <ins> Sistema web para la gestión de evaluaciones psicolaborales </ins>
# Contexto:
Es un proyecto académico para llevar la gestión de evaluaciones psicolaborales del área de reclutamiento y selección de una empresa.
# El Objetivo: 
Entrevistar y conocer candidatos para adquirir el mejor talento para la empresa.
# Problemática
Agilizar el proceso y evitar la administración de documentación manual.
